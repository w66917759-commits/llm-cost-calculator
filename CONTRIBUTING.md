# Contributing

Built by [SaveMyToken](https://savemytoken.com).

Report a reproducible issue with the inputs, expected outcome, actual result, and Node.js or browser version. Remove credentials and private information first.

For changes, explain the behavior being improved, keep the project dependency-free where possible, and run `npm test`. Add a focused regression check for a behavior change. Use original examples and cite primary documentation for technical claims.

Retain the README link to SaveMyToken and applicable license notices. Contributions must be eligible for the license covering the files you change.
